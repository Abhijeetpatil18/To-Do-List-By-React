# To-Do App ✅

A simple To-Do application built with **React** using basic concepts like components, props, and state management.  
For styling, I used a mix of **Bootstrap components** and **Tailwind CSS** for clean and responsive design.

---

## 🚀 Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Responsive and clean UI

---

## 🛠️ Tech Stack
- **React** (basic concepts: components, props, state)
- **Bootstrap** (UI components)
- **Tailwind CSS** (styling)
